Connect to GitHub

One-time setup. On GitHub: Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token. Choose Only select repositories (this repo only), under Permissions set Contents: Read and write, set an expiry, and paste the token above. It is saved only in this browser, never on the website. Anyone who opens this page without the token cannot change anything.

Add paintings
